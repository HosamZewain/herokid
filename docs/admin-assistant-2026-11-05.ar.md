# مساعد Auto Pilot — مرحلة القراءة والتشخيص

الحالة: تنفيذ محلي على `codex/admin-assistant-20261105` مبني على Main وAWS المتحقق منهما `5420bc2b94afb07b568f6610d11eb8f9e24090e2`. **غير منشور، وغير مفعّل على الإنتاج.** التوجيه الحالي «ابدأ» يجيز التنفيذ والاختبارات؛ لا يضيف نشرًا أو تفعيلًا لصلاحيات تنفيذ جديدة.

## ما تم تنفيذه

نافذة RTL فاتحة من صفحات الإدارة، مع سؤال حر، اقتراحات، عرض حقائق وروابط مصادر ووقت القراءة. يدعم تشخيص أوردر برقم HK أو ID، قراءة كل وحداته وأسباب الانتظار عبر `OrderContextBuilder` و`CapabilityRegistry`، قائمة أقدم20أوردر نشط في نطاق المستخدم، ملخص تقييم Auto Pilot، وملخص المبيعات وحركات التحصيل من خدمات التقارير القائمة. لا يدعي ترتيب تنفيذ FIFO، ولا يساوي التقييم/الإنتاج بالتسليم، أو صافي الدفعات بتحصيل نقدي مثبت مستقلًا أو الربح. حتى20وحدة و20سببًا في الرد مع توضيح الحدود.

يفهم المزوّد سؤال المستخدم ويختار **قارئًا واحدًا محددًا**. تطبيق Laravel يفرض الصلاحيات، يسترجع البيانات ويبني الرد من الحقائق؛ لا يرسل بيانات الأوردرات أو نتائج التقارير للموديل، ولا يقبل SQL أو URL أو اسم دالة منه. يستخدم نفس مصادر MCP الحالية مباشرة داخل التطبيق، دون توكن MCP واسع الصلاحية في المتصفح أو فتح endpoint MCP القديم. الأدوات الحالية للقراءة ليست تفويضًا لهوية الموظف.

المرحلة لا تجيب عن كل التقارير والتفاصيل الممكنة: الشحن/المصروفات/أداء الموظفين والتصدير والمقارنات المعقدة ليست موصولة بعد. الفلاتر غير المدعومة تنتج توضيحًا بدل إجمالي غير مفلتر. طلب «كمّل/أرسل/أعد التوليد» يوضح أنه لم ينفذ ويعرض رابط الإجراء الأصلي؛ **لا توجد write tools**. المرحلة التالية تحتاج عقد إجراء محدد، إعادة تحقق السياسات والنسخة والهوية والموافقات والميزانية ومنع التكرار، وسجل على الأوردر؛ لا تغير هذه المرحلة الملكية أو الإيقاف أو الموافقات أو الذاكرة.

## الصلاحيات والخصوصية

- هوية جلسة Laravel الحالية، admin نشط غير Agent API؛ نفس `orders.view`/`sales_reports.view` و`orders.statistics.view` للحقول المالية. لا يمنح الشات صلاحية جديدة.
- `OrderAccess` يقيّد الاستعلامات بالأوردرات المسندة للموظف؛ لا تعرض التقارير العامة أو لوحة Auto Pilot لمستخدم assigned-only. استثناء `EnforceOrderAccess` محصور في نقطتي الشات اللتين تطبقان التحقق؛ بقية شاشات الإدارة كما هي.
- تحميل مستخدم جديد وفحص توقيع الصلاحيات ونطاق الإسناد قبل المزوّد وبعده وبعد القراءة. مصدر غير متاح يعطي نفس404لرقم غير موجود وخارج النطاق. إخفاء أسباب الدفع التفصيلية والمبالغ لغير المخوّل.
- لا تاريخ محادثة دائم أو localStorage أو shared answer cache. توكن مشفر15دقيقة يحمل محدد المورد فقط، مربوط بالمستخدم والصلاحيات؛ لا يحمل إجابات أو سجلات الأوردر. تُقرأ الحقائق من جديد لكل سؤال.
- واجهة الشات تمسح العرض عند الإغلاق/مغادرة التبويب أو تغير توقيع الصلاحيات. تفحص صلاحيات العرض أثناء فتحها. أي معلومات سبق أن شاهدها المستخدم لا يمكن محوها من ذاكرته أو من نسخة سبق له حفظها.
- سجلات التدقيق تحمل اسم الأداة وread_only وبصمة السؤال فقط؛ تستثني سؤال المستخدم والتوكن والرد وحقائق التقارير من التدقيق الآلي. العرض يستخدم textContent وروابط مصدر محلية، وليس HTML صادرًا عن الموديل.

## المزوّد وحدود التشغيل

`assistant-bridge.mjs` عملية/socket منفصلان، مع نفس حواجز Linux read-only/non-root/no-new-privileges/seccomp، الشبكة عبر proxy المسموح فقط، صفر أدوات للنموذج، وإلزام مصادقة الاشتراك بلا API fallback. `bridge.mjs` وعامل قرارات Auto Pilot لم يتغيرا. استدعاء تصنيف واحد بمهلة25ثانية؛ لا retry تلقائي أو حلقات. رفض shell/file/network events كما في runtime القائم. حصة5000للقرارات لا تُعدل؛ الشات له عداد تهدئة مستقل6أسئلة/دقيقة/مستخدم، وطلب واحد لكل مستخدم في نفس الوقت، وتصنيف واحد متزامن لكل bridge. حدود الاشتراك لدى المزوّد تظل مستقلة عن هذه الأرقام.

الاعتماد البرمجي يبقى SDK/CLI0.166.0 المثبت بالمشروع. مرجع الاستخدام العام: [OpenAI Codex SDK](https://developers.openai.com/codex/sdk). لا ترقية dependencies أو افتراض توفر موديل جديد.

الواجهة مغلقة افتراضيًا عبر `ADMIN_ASSISTANT_ENABLED=false`. عند نشر معتمد لاحقًا: إعداد socket `/run/herokid-assistant/decision.sock` مستقل، UID/مجموعة وصلاحيات محددة، جلسة اشتراك مخصصة مصادق عليها، image hash معتمد، واختبار startup isolation/auth وقراءة حقيقية قبل التفعيل. `assistant.compose.yaml` override يُستخدم بمشروع مختلف وبمسارات auth/socket منفصلة؛ **لا تشغله فوق مشروع Auto Pilot**. لا نسخ صامت لاعتماد سطح المكتب أو عامل الإنتاج. التوقف أو غياب المزوّد يعرض503ولا يغيّر الأعمال الجارية. لا migration أو خدمة AWS مدفوعة جديدة؛ الاستضافة/تخصيص موارد العملية يراجع عند تجهيز النشر.
