# دعم البوستر في الأوتوميشن وAuto Pilot

الحالة: **مجهز ومختبر، غير منشور**. طلب المالك إضافة دعم البوستر بعد مراجعة HK11-117. قاعدة النسخة المعزولة هي `a76d735dd8015921b9c73d26c7d5a3c9856a19e3` من Main، وتشمل تحسين أولوية الجاهز في Auto Pilot. التعديلات المحلية في نسخة الموبايل الأساسية لم تُمس.

## السبب والتغيير

المنتج `bostr-mkhss-bsor-altfl-mkas-a4` يُنتج صورة واحدة ببرومبت صالح. المنع كان قائمة أنواع المنتجات في `puzzle_automation.product_slugs` التي سمحت بالبازل والمج فقط. نفس القائمة تستخدمها قراءة قدرات Auto Pilot، وإدراج أحداث التأكيد، وحجز التنفيذ، وفحص مدخلات المنتج.

- أضيف البوستر إلى القائمة المشتركة، دون السماح تلقائيًا لكل منتجات الكتالوج أو تجاوز فحص مكونات المنتج والصور والتكلفة والحالة والصلاحيات والإيقاف.
- طُلبت صورة طولية `1024x1536` للبوستر. المقاس المشترى وتفاصيل الفريم يظلان في بيانات وبرومبت البند؛ لا تغيير لخيارات 20×30 و30×40 أو أسعارها. ملف التوليد ليس إثبات دقة 300DPI أو اعتمادًا للطباعة؛ تظل مراجعة القص والمقاس وجودة الطباعة في Studio مطلوبة.
- فحص جودة صور المنتجات يستخدم مقاس الطلب المحفوظ بدل افتراض صورة أفقية دائمًا. فحص كفر A4 مستقل كما كان. الصورة ذات الاتجاه أو الدقة غير الصحيحة تظل محفوظة للمراجعة ولا تُنشر ولا تُعاد تلقائيًا.
- البوستر يدخل من الأوتوميشن القائم أو من إجراء Auto Pilot الحالي `generate_product_image`؛ لا موصل جديد أو حصة أو مزود أو استدعاء API مختلف.
- مسار المعاينة المختلطة الحالي يضم البوستر مع بقية الصور. الصور المكتملة لا تُولد مرة ثانية، والموافقة والدفع اللازمان للصفحات الداخلية لا يتغيران.

## التحقق

- PHP 8.3.3: **163 اختبارًا /1626 تأكيدًا** على كل من SQLite وMySQL 8.4 معزولين، ببيانات صناعية ومزود صور وهمي وHTTP محظور إلا الاستجابات الوهمية في الاختبارات.
- اختبارات جديدة تثبت توليد البوستر الطولي وحفظ الأصل والمعاينة مرة واحدة؛ حفظ نتيجة أفقية خاطئة للمراجعة؛ إدراج Auto Pilot مرة واحدة مع الحفاظ على شقيقة مكتملة؛ اكتمال معاينة طلب يجمع قصة وبازل وبوستر وكتاب تلوين ومج.
- الاختبار المختلط فشل قبل التغيير بـ`puzzle_ineligible`، واختبار Auto Pilot فشل لأن البوستر غير مدعوم؛ كلاهما نجح بعد التغيير.
- الفحص المرشح على بيانات HK11-117 كان داخل معاملة MySQL للقراءة فقط، مع تحميل `PuzzleInputs` المرشح وإعداد البوستر في ذاكرة عملية التشخيص وحدها. لم تُعدل ملفات التطبيق أو cached config أو الطلبات أو الطوابير على الإنتاج.
- البند3123 اجتاز الفحص، بصورتين للطفل ومقاس `1024x1536` وتكلفة تقديرية0.165USD. قراءة Auto Pilot المرشحة أعادت `execute / generate_product_image / READY_FOR_PRODUCTION_PREFLIGHT`.
- البندان3122 و3125 ما زالا `succeeded`، وبصمات مدخلاتهما مطابقة للمدخلات الحالية. لم يُكرر توليدهما ولم يُرسل شيء للعميل ولم يُستدع مزود مدفوع في التشخيص.

## النشر المرتقب وحدوده

النشر يحتاج اعتماد هذه الإضافة وفق AGENTS.md. هذه المذكرة لا تثبت تطبيق الدعم على AWS أو بدء البوستر فعليًا. الطلبات المتوقفة يدويًا لا تُفعّل ولا تُعاد محاولات قديمة كجزء من الإصدار.

1. إعادة التحقق من SHA وMain والانحدار، والاحتفاظ بأي نشر أحدث وتعديلات غير مرتبطة.
2. checkpoint خاص للشفرة وcached config وتوثيق التجزئات؛ قفل نشر يغطي المعاملة كاملة. لا ترحيل أو بناء أصول أو تثبيت تبعيات مطلوب لهذا التغيير.
3. cached config الإنتاجية تتضمن إعدادات Auto Pilot خاصة. **لا تشغّل `config:cache` أو `config:clear` عشوائيًا**. حدّث فقط `puzzle_automation.product_slugs` و`puzzle_automation.product_sizes` بالقيم المراجعة، مع الاحتفاظ بالإعدادات الأخرى و`.env` والحصص وحد الإضافة التاريخية `after_event_id` والصلاحيات كما هي. أثبت تطابق جميع المفاتيح الأخرى قبل وبعد، واحفظ نقطة استرجاع خاصة بصلاحياتها الحالية.
4. تحديث هادئ ومحدد للعمال الذين يحملون خدمات إدراج/توليد المنتجات وAuto Pilot بعد انتهاء العمل الجاري، وإعادة تحميل FPM. لا توقف طلب صور مدفوعًا في منتصفه، ولا تعد تشغيل مولد مشاهد Codex دون حاجة.
5. التحقق من SHA وتجزئات الملفات وقيم الإعداد المحددة، وفحص بيانات البوستر للقراءة فقط، وHTTPS والخدمات والأخطاء الحديثة. لا طلبات إنتاج أو رسائل تجريبية للعملاء ولا تغيير يدوي لحالات HK11-117 أو إعادة jobs قديمة.
6. تراجع متوافق عن الشفرة والإعداد المحدد فقط بعد فحص أي توليد بوستر بدأ في الإصدار؛ احتفظ بالصور والإيصالات والدفعات والكتابات اللاحقة. لا DB restore أو S3 delete أو queue replay.

التقدير واجتياز الفحص لا يثبتان انتهاء توليد فعلي أو وصول المعاينة. بعد النشر يعتمد قبول العمل على رصد Auto Pilot وإعداداته وفحوص العامل الحالية، أو إجراء الفريق المسموح من الواجهة.
