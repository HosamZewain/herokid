# إدارة الطلبات والإسناد والإيقاف الآمن — 3 نوفمبر 2026

## النطاق

الموظف المسؤول مستقل عن حجز التنفيذ الآلي. الإسناد على مستوى عملية الشراء ويحفظ سجل المنفذ والسبب والمسؤول السابق والجديد، مع رقم مراجعة يمنع تعارض مديرين حتى بعد إزالة الإسناد. تشغيل أو إيقاف الأوتوميشن لا يعيد توزيع الموظفين.

القائمة تعرض كل الأنواع افتراضيًا، وتبويبات الكل/الأوتوميشن/الفريق/التدخل، مع فلاتر الموظف والمرحلة وحالة التنفيذ. الملخص مجمّع من سجلات التأكيد والهويات والمنتجات والمعاينات والدفع وCodex، ويبرز الفشل الجزئي دون إخفاء توليد جارٍ. التحديث كل 10 ثوانٍ يتوقف عند إخفاء الصفحة ويحفظ التحديدات والمدخلات؛ تغيّر النتائج يحتاج تحديثًا صريحًا للقائمة.

شريط التفاصيل يظهر حتى عند عدم وجود تشغيل Codex. صفحات كتب التلوين بـCodex والكفر بـOpenAI. كتاب مدفوع ومعتمد دون تشغيل يظهر سببًا وزر فحص وبدء؛ لا توجد إعادة معاينة عميل بعد الصفحات الداخلية. اكتمال الكتاب يعيد حالة العمل الحالية «تم الإنتاج والموافقة» (المفتاح القديم delivered)، مع بقاء الطباعة والشحن مستقلين.

## الصلاحيات

- orders.assignment.manage: إسناد/نقل/إزالة فردية أو جماعية.
- orders.view_all: رؤية الجميع عند تشغيل assigned-only.
- orders.automation.control: تحكم في الطلبات المسندة للمستخدم، أو الجميع إذا معه view_all؛ صلاحية update مطلوبة أيضًا.
- orders.visibility.manage: تغيير وضع الرؤية، مع view_all وإدارة الإسناد حتى لا تُفقد إمكانية توزيع غير المسند.
- صلاحيات الصور والبرومبت والدفع والتعديل تبقى مستقلة.

الوضع الافتراضي all. لا يُعاد توزيع أي طلب. مزامنة سجل الصلاحيات تحدث دور المالك؛ لا تُمنح الصلاحيات الجديدة تلقائيًا لكل الموظفين. المدير يضبط صلاحيات الفريق قبل تفعيل التقييد.

التقييد يطبق في الخادم على استعلامات الطلبات والروابط والإجراءات والملفات والتصدير والتقدم؛ نقل الطلب يسحب الوصول في الطلب التالي. الكتالوج المستقل يحتفظ بصلاحياته. شاشات التقارير والعملاء والوسائط المشتركة غير القابلة لتقييدها بطلب واحد تتطلب view_all؛ المعاينات الداخلية المرتبطة بطلب تُفحص بمالك الطلب. عمال الخلفية وAgent API والروابط العامة للعملاء لا يتغير نطاقها.

## الإيقاف والاستئناف

running → pause_requested → paused، أو pause_uncertain إذا لم يتأكد العامل. يُمنع قبول خطوة جديدة بعد الطلب، وتُحفظ المحاولة المقبولة بالفعل. Codex يتوقف عند نهاية الصفحة، ثم يجمع Laravel الصورة ويتحقق من S3 قبل تسليم الطلب. لا يقتل الزر العامل أثناء التوليد.

الاستئناف يعيد فحص البصمة والاعتمادات والدفع والصور المقبولة. النتائج المجهولة لا تُكرر، والمحاولات المنتهية بفشل تحفظ أسبابها. ملفات العامل تحتوي معرف التشغيل والطلب والمنتج وبصمة manifest؛ تغييرها يمنع الاستكمال. وقت الوقوف اليدوي منفصل عن وقت التوليد.
